# nopCommerce Manual Testing

Manual QA testing project for the nopCommerce demo store.

## Project Overview

This project demonstrates my practical skills in manual software testing.

The project includes:
- Test Plan
- Checklist
- Test Cases
- Bug Reports
- Test Summary Report
- DevTools Testing
- Screenshots as test evidence

## Tested Areas

- Registration
- Login
- Search
- Wishlist
- Shopping Cart
- Checkout
- My Account
- Product pages
- Filters and sorting
